# Boulangerie du Coin — Site web (fictif)

Ce petit site statique montre la mise en page d'une boulangerie en utilisant les images présentes dans ce dossier.

Pour visualiser le site :

1. Ouvrez le dossier `boulangerie` dans votre explorateur de fichiers.
2. Ouvrez `index.html` dans un navigateur (double‑clic ou glisser/déposer).

Aucune dépendance ni serveur n'est requis. Le formulaire de contact est simulé en local.
